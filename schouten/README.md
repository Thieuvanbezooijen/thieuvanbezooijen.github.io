# Schouten Dental – Website mockup

Statische design/mockup van [sgdentalshop.com](https://sgdentalshop.com/). Geen echte webshop – placeholders voor tekst, afbeeldingen en prijzen.

## Starten

Open `index.html` in de browser, of start een lokale server:

```bash
python3 -m http.server 8080
```

Ga daarna naar http://localhost:8080

## Pagina's

- **Home** – hero, productrails, nieuws, merken, contact, SEO-blok
- **Categorie / product / merken / zoeken / winkelwagen / account**
- **Support, reparatie, klantenservice, informatiecentrum**
- **Over ons, vacatures, training, brochures, download centrum, afspraak**
- **Privacy & voorwaarden** (placeholder)

Gedeelde header (mega-menu), footer en styling via `css/styles.css` en `js/site.js`.
